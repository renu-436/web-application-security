# Web Application Security

## Overview

This repository contains my practical work and learning notes for Web Application Security as part of my cybersecurity internship.

The activities are performed in a controlled lab environment using DVWA (Damn Vulnerable Web Application) on Kali Linux.

## Objective

The objective of this task is to understand, identify, and demonstrate common web application vulnerabilities and their security mitigations.

## Tools and Technologies

- Kali Linux
- DVWA
- Apache Web Server
- MariaDB
- Burp Suite
- Firefox
- PHP
- Git and GitHub

## Topics Covered

1. SQL Injection
2. Cross-Site Scripting (XSS)
3. Cross-Site Request Forgery (CSRF)
4. File Inclusion
5. Burp Suite
6. Web Security Headers
